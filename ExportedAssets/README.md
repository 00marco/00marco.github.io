# Living Notes export assets

Ready-to-copy PNG assets generated from the current Living Notes visual system.

- `Plants/`: transparent 624 px plant artwork for every foliage stage (0–5) and pot stage (0–4), decay examples, and a contact sheet.
- `Screens/`: Garden, Note Thread, and Search listing compositions for iPhone 15 portrait (`1179×2556`) and iPad 11-inch landscape (`2388×1668`).
- `generate_export_assets.py`: reruns the export using Pillow.

Run `python3 ExportedAssets/generate_export_assets.py` from the repository root to regenerate everything.
